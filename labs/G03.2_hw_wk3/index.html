In this homework, based on the lab exercises, you will experiment with creating your own LangChain agent by augmenting the lab examples with additional tools or architectures. The LangChain tools doc page is here. Custom functionality can include (in increasing level of difficulty):

  • Adding support for additional built-in tools and toolkits not contained in the lab exercises
  • Adding custom tools (such as utilizing your RAG application from your previous homework)
  • Adding custom architectures (Multi-agent/LangGraph, CrewAI, or Plan-and-Execute agents)

Finally, your agent should:

  • Retain one of either the PythonREPL tool or the Terminal tool within it.

Your development should be organized and incremental, with frequent commits into your git repository. Code should also be properly documented via Python docstrings. Use the uv virtual environment manager to isolate your project dependencies. Use a virtual Python environment as demonstrated in Lab02 Codelabs. In addition, you must also ensure API keys do not show up in your source files, but rather are passed in via environment variables. Ensure your application code is pushed to your repository before class.

Screencast

Upon completing your agent, via a narrated screencast of no longer than 5 minutes, you will perform a demonstration and source code walk-through of the agent. Ensure that the video camera is turned on initially in your screencast. The screencast should follow the order of the script below.

  • Check out the application source code from your course repository with git clone.
  • Demonstrate the application running showing both its capabilities as well as its limitations
  • Perform a source code walk-through via the git commits on Gitlab to explain how the application has been incrementally implemented.

Screencast Upload Instructions
