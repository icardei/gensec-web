In this homework, you will utilize any coding agent (Aider, AntiGravity, Cursor, Claude Code, Copilot) to produce a secure application of your choice from only prompts. The goal of the exercise is to get practice producing a functional Python application using as little effort as possible via a coding agent. Some example applications include generating:

  • Code for an entire LLM application
  • A Python web application for querying a RAG application drawn from security sources
  • An OAuth-enabled web application
  • A network traffic analyzer and visualizer
  • A web-based steganography tool
  • A re-implementation of functions found in common security tools such as nmap, hydra, wfuzz, commix, or xsstrike.
  • A web site or code fuzzer for testing web sites or programs for errors
  • A macro for an Excel spreadsheet that runs an executable when opened that exfiltrates data on a machine
  • A DLL that launches cmd.exe when loaded using RunDLL to create a backdoor

As the application is developed, keep track of the main prompts utilized to generate the code of your application in prompts.txt, in order to replay its recreation for your screencast. Upon completion of the application, push the resulting code and prompts (or URLs to prompt sessions) to your repository before class.

Screencast

Upon completing your application, you will replay the development and demonstration of your application from scratch using the prompts in prompt.txt via a narrated screencast of no longer than 5 minutes. Ensure that the video camera is turned on initially in your screencast. The screencast should follow the order given below:

  • Check out the homework from your course repository.
  • Perform an overview walk-through of the prompts in prompts.txt.
  • Perform a replay of the prompts in prompts.txt to generate your application
  • Demonstrate the application produced showing its capabilities as well as its limitations

Upload your completed screencast on MediaSpace. Ensure that it is published as "Unlisted". Then, update the file screencast_url.txt in the homework's directory to contain the URL that your unlisted screencast on MediaSpace is located. Push the changes that include the updated URL to your repository before class.
