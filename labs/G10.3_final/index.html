For your final project, you will experiment with creating your own MCP clients, MCP servers, and skills, for performing threat intelligence or other defensive tasks not found in the lab exercises. You must develop an agentic application that demonstrates your understanding of the concepts and techniques learned in this course. You may use any of the libraries or tools covered in the course, as well as any additional libraries or tools that you find useful. Custom functionality can include:

  • Orchestrating the use of a range of security APIs found here, here, here, or here or additional security tools found here, here, or here.
  • Threat intelligence applications (e.g. services such as Greynoise, Shodan, AlienVault OTX, AbuseIPDB)
  • Defensive applications (e.g. revoking or rotating cloud or API keys, automated system hardening, analyzing log files and security alerts)

As the application is developed, keep track of the main LLM prompts utilized to generate the code of your application in file prompts.txt, in order to replay its recreation for your screencast. Take screenshots of the prompts and the agent's replies, and copy them to the Project Word document. Upon completion of the application, push the resulting code and prompts file to your project repository.

Upon completing your application, via a narrated screencast of no longer than 15 minutes, you will perform a demonstration and source code walk-through of the application. Ensure that the video camera is turned on initially in your screencast. The screencast should follow the order given below:

  • Check out the application source code from your course repository.
  • Demonstrate the application running showing both its capabilities as well as its limitations
  • Perform a source code walk-through via the git commits on Gitlab to explain how the application has been incrementally implemented.

Upload your screencast video file to your Youtube account. Ensure that it is unlisted and that the video URL is accessible without an account. Use your browser in incognito mode to check the video URL. Add the recording URL to the Project Word file. Push the changes that include the updated URL to your repository when done.

Project Submission

Follow these instructions to submit your project on Canvas:

  1. Ensure the latest Project code is pushed to your course repository on Github.
  2. Enter your repository URL on the provided field in the project Word document.
  3. Enter the screencast URL on the provided field in the project Word document.
  4. Copy screenhsots with all prompts and the agent's replies to the project Word document.
    • Ensure these have a readable font size, are clear and legible to get any credit.
  5. Convert the Word document to PDF.
  6. Upload the PDF to the Poject Canvas page before the deadline.
  7. Doublecheck the PDF file uploaded on Canvas, including the Github repo link from the PDF file and the youtube screencast URL.
